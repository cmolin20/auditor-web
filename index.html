Auditor web de centre

Revisa la web Nodes del centre en un minut: protecció de dades, metadades dels fitxers, ús d'IA, accessibilitat, imatges, contingut caducat i enllaços. No cal instal·lar res ni tenir accés d'administració.

Revisió sense servidor (botó de marcadors)
1Instal·la el botó

Arrossega'l a la barra de marcadors (Ctrl+Maj+B si no la veus).

Auditor web

2Executa'l a la web

Obre la portada de la web del centre, clica el marcador i, quan acabi, «Copia els resultats».

3Enganxa els resultats
