Auditor web de centre

Escriu l'adreça de la web del centre i en un minut tindràs un informe amb el que cal arreglar: dades personals publicades, fotos i documents, ús de la IA, accessibilitat i documents antics. Cada problema porta els passos per solucionar-lo. No cal instal·lar res ni tenir l'usuari d'administració.

Revisió sense servidor (botó de marcadors)
1Instal·la el botó

Arrossega'l a la barra de marcadors (Ctrl+Maj+B si no la veus).

Auditor web

2Executa'l a la web

Obre la portada de la web del centre, clica el marcador i, quan acabi, «Copia els resultats».

3Enganxa els resultats
